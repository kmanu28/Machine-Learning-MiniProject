# Reference material

These files are supporting material for the course assignment and the paper
reproduction. They are kept here so the project root contains only the code,
data folders, reports, and configuration files needed to run the work.

- `58.pdf` — source/reference paper supplied for the reproduction.
- `Guidelines and Instructions_Mini Project Assignment.pdf` — mini-project
  assignment brief and submission requirements.
- `poster.pdf` — project poster draft/reference.
- `Stanford_Coding Assignment _Problem_Statements.xlsx` — course problem
  statement list.
